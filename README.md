# The World in One Picture — 24 Nov 2026

This repository is an entry to the make.fun bounty at https://make.fun/bounty/news-image-20261124. Its program (`main.py`) deterministically copies `entry.png`—a one-page newspaper image summing up the world news of Tuesday 24 November 2026 (Jensen Huang reinstated as Nvidia CEO as shares soar 31%, Ukraine sinking a Russian warship off Libya, the EU unveiling its 22nd sanctions package, and New Zealand batting out a draw after India's record 720)—to the output directory.

## Run it

```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
